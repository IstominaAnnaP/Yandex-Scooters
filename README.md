# 🛴 Тестирование сервиса «Яндекс Самокат» (Manual & UI Automation)

Комплексный проект на курсе Яндекс Практикум по ручному тестированию и автоматизации тестов для сервиса аренды электросамокатов **«Яндекс Самокат»** .

---

### 📋 Что было сделано

#### 1. Ручное тестирование (Web & Mobile)
- Проведен тест-анализ требований и применены техники тест-дизайна: **классы эквивалентности (КЭ)** и **граничные значения (ГЗ)**.
- Составлена тестовая документация для веб- и мобильного приложения: **чек-листы** и **тест-кейсы**.
- Проведено функциональное и UI-тестирование веб-приложения по подготовленной документации.
- Заведены подробные **баг-репорты** с шагами воспроизведения, фактическим/ожидаемым результатом.

#### 2. Автоматизация UI-тестирования веб-приложения
- Написаны автотесты на **Python + Pytest + Selenium WebDriver** (запуск в браузере **Firefox**).
- Использован паттерн проектирования **Page Object Model (POM)**.
- Подключено формирование наглядных отчетов о прохождении тестов с помощью **Allure**.

---

### 🛠 Стек технологий и инструментов
- **Язык и фреймворки:** Python, Pytest, Selenium WebDriver
- **Отчетность и контроль версий:** Allure, Git, GitHub
- **Тестирование UI и верстки:** Figma, Chrome DevTools (инспектирование элементов DOM)
- **Перехват и подмена трафика:** Charles Proxy (подмена ответа от бэкенда для изменения времени сервера)
- **Тестовая документация:** Google Docs

---

### 📂 Структура репозитория
- `/docs` — ссылки или файлы с чек-листами, тест-кейсами и баг-репортами
- `/pages` — описание страниц и локаторов (Page Object)
- `/tests` — директория с UI-автотестами
- `requirements.txt` — список зависимостей проекта

---

### 🚀 Как запустить автотесты локально

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com
   cd название_вашего_репозитория
   ```

2. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Запустите тесты с сохранением результатов для Allure:**
   ```bash
   pytest --alluredir=allure-results
   ```

4. **Сформируйте и откройте отчет Allure:**
   ```bash
   allure serve allure-results
